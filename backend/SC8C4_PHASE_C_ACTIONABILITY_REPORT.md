# SC-8C4 Phase C — Actionability & Execution Coverage Contract Report

## 1. Objective

Phase C formally defines which SC-8C2 detection findings are executable and which must remain detection-only. It does **not** add new remediation executors; it only adds the contract layer that prevents unsupported or unsafe findings from being dispatched.

## 2. Design Principles

* **Safety authorities are never overridden.** `SafetyAssessment`, `Fixability`, `SafetyGate`, protected-location rules, and missing/locked/inaccessible state checks still take precedence.
* **Contract is subordinate to safety.** `CapabilityContract.resolve` checks safety and fixability before the matrix is ever consulted.
* **No invented remediation.** If a `(RuleCategory, AssetType, ActionType)` tuple is not in the matrix, the finding is `UNSUPPORTED` and cannot become a `PLANNED` action.
* **No target executor for detection-only findings.** `ActionPlanner` produces `ActionType.NONE` + `ActionState.NOT_FIXABLE` for unsupported findings. `DefaultExecutor` rejects such actions through `SafetyGate` before any filesystem, registry, browser, or startup executor is invoked.

## 4. Capability Contract

### 4.1 Actionability Verdicts

| Verdict | Meaning |
|---------|---------|
| `ACTIONABLE` | A supported `(category, asset_type, action_type)` exists, safety is `SAFE`/`LOW_RISK`, fixability is `AUTO_FIXABLE`, and the rule declares `REMEDIATION_AVAILABLE` |
| `DETECTION_ONLY` | No remediation path, or fixability/safety prevent automatic action |
| `REVIEW_REQUIRED` | Safety or rule capability requires human approval |
| `BLOCKED` | Safety assessment or fixability is `BLOCKED` |
| `UNSUPPORTED` | Category/asset/action combination has no executor support |

### 4.2 Supported ActionTypes

The matrix explicitly permits the following SC-8C3/SC-8C4 action types:

- `delete_file`
- `delete_directory`
- `clear_cache`
- `remove_registry_value`
- `remove_registry_key`
- `disable_startup_entry`
- `clear_browser_cache`

All other action types (e.g., `reset_setting`, `quarantine`, `repair`, `optimize`) remain unsupported and detection-only.
